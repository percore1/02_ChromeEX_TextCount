# TextCount

ウェブページや原稿ファイルから文字数を、指定ルールで自動カウントする Chrome 拡張機能です。  
サイドパネルが常時表示され、自動同期・テキスト貼り付け・ファイルアップロードの3つの方法でカウントできます。

---

## 機能

- **3つの入力方法**
  - **自動**：ページ上のテキストを選択するとリアルタイムにカウント
  - **貼り付け**：サイドパネル内のテキストエリアに貼り付けてカウント
  - **ファイル**：`.txt` / `.docx` ファイルをドラッグ＆ドロップしてカウント
- **除外ルールの自動適用** — 見出し・URL・引用行・リストマーカーなどを自動除外し、本文の文字数のみをカウントします
- **テキストプレビュー** — 除外処理後のテキストをサイドパネル内で確認できます

---

## 動作環境

- Chrome 116 以上（Side Panel API を使用）
- Manifest V3

---

## インストール方法（開発者モード）

1. このリポジトリをクローンまたは ZIP でダウンロードして展開します
2. Chrome で `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. ダウンロードしたフォルダ（`manifest.json` があるディレクトリ）を選択します

---

## 使い方

1. カウントしたいページを開きます
2. Chrome ツールバーの **TextCount アイコン** をクリック → 画面右側にサイドパネルが開きます
3. サイドパネル上部のタブから入力方法を選びます

### タブ1：自動

ページ上でテキストを選択するだけで自動的にカウントされます（通常のWebページ向け）。

### タブ2：貼り付け

テキストエリアに任意のテキストを貼り付けてカウントします。  
**Googleドキュメントの本文をカウントしたい場合はこのタブを使ってください。**

> Googleドキュメントは2021年以降 Canvas ベースのレンダラーへ移行しており、選択テキストを外部から取得できない仕様になっています。本文を `Ctrl+A` → `Ctrl+C` でコピーし、貼り付けタブに貼り付けてご利用ください。

### タブ3：ファイル

ドロップ領域に `.txt` または `.docx` ファイルをドロップ（またはクリックして選択）します。  
原稿ファイル全文を一括でカウントできます。

## 除外ルール一覧

| ルール | 対象 | 自動 | 貼り付け / .txt | .docx |
|---|---|:---:|:---:|:---:|
| スペース・改行・タブ | 全角スペース含む空白文字全般 | ✓ | ✓ | ✓ |
| 見出し（DOM） | `h1`〜`h6` タグで囲まれた要素 | ✓ | − | ✓ |
| 引用ブロック | `blockquote` タグで囲まれた要素 | ✓ | − | ✓ |
| 見出しタグ（文字列） | `<h1>`〜`<h6>` がテキストとして含まれる場合（**全角括弧 `＜＞` にも対応**） | ✓ | ✓ | ✓ |
| 引用元・出典行 | `引用元：`、`参照：`、`出典：` などを含む行 | ✓ | ✓ | ✓ |
| URL | `https://`、`http://`、`www.` で始まる文字列 | ✓ | ✓ | ✓ |
| リストマーカー | `・` `●` `○` `►` `▶` `※` および行頭の番号リスト（`1.` `1）` 等） | ✓ | ✓ | ✓ |
| 価格表記 | `¥/￥ + 数値`（例：`¥1,200`）または `数値 + 円`（例：`1,200円`） | ✓ | ✓ | ✓ |

※ プレーンテキスト（貼り付け・.txt）では DOM 構造が無いため、DOM ベースの見出し・引用ブロックは検出できません（文字列としての見出しタグは検出されます）。  
※ `.docx` は内部で HTML に変換されるため、すべての除外ルールが適用されます。

## 要確認項目（警告）

以下のケースが検出された場合、プレビュー上部に「⚠ 要確認項目」として表示されます。

- 見出しタグに**全角括弧（`＜` `＞`）**が含まれている
- 見出しタグの**開閉数が一致しない**（例：`<h2>` が3個に対し `</h2>` が2個）

警告が表示された場合も、可能な範囲で除外処理は実行されますが、原文の修正を推奨します。

## サイドパネルの見方

```
┌─────────────────────────┐
│ TextCount      [同期中] │  ← 選択中は緑のバッジが表示
├─────────────────────────┤
│ [自動] [貼り付け] [ファイル] │  ← タブ切替
├─────────────────────────┤
│  入力エリア（タブごと）   │
├─────────────────────────┤
│  カウント対象文字数       │
│        1,234 文字        │  ← 除外後の文字数
├─────────────────────────┤
│ 元文字数      1,500 文字 │
│ 除外文字数      266 文字 │
├─────────────────────────┤
│ 適用した除外ルール        │
│ ✓ スペース・改行を除外   │
│ ✓ URL を除外             │
├─────────────────────────┤
│ ⚠ 要確認項目（警告時のみ）│
│ ⚠ 全角括弧を含む見出し...│
├─────────────────────────┤
│ プレビュー  [📋 コピー]  │
│ （除外後テキスト）        │
└─────────────────────────┘
```

## ファイル構成

```
├── manifest.json            # 拡張機能の設定ファイル
├── background.js            # サービスワーカー（サイドパネルの起動設定）
├── content.js               # ページに注入されるスクリプト（選択検出・テキスト処理）
├── sidepanel.html           # サイドパネルのHTML
├── sidepanel.css            # サイドパネルのスタイル
├── sidepanel.js             # サイドパネルのロジック（タブ切替・貼り付け・ファイル処理）
├── mammoth.browser.min.js   # .docx → HTML 変換ライブラリ（外部）
└── README.md                # このファイル
```

### 使用ライブラリ

- [mammoth.js](https://github.com/mwilliamson/mammoth.js)（BSD 2-Clause License）— `.docx` ファイルを HTML に変換するために使用
