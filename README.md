# TextCount

ウェブページや原稿ファイルから、文字数のカウントとローカルルールベースの校閲チェックを行う Chrome 拡張機能です。  
サイドパネル上で、自動同期・テキスト貼り付け・ファイルアップロードの3つの入力方法に対応しています。

---

## 機能概要

サイドパネルは **機能タブ（外側）×入力タブ（内側）** の2階層構造です。

```
[ 文字数カウント ] [ 校閲チェック ]      ← 外側（機能タブ）
  ┌────────────────────────────┐
  │ [ 自動 ] [ 貼り付け ] [ ファイル ]  ← 内側（入力タブ）
  │   ─ 入力エリア / 結果エリア ─
  └────────────────────────────┘
```

### 文字数カウント

- **3つの入力方法**
  - **自動**：ページ上のテキストを選択するとリアルタイムにカウント
  - **貼り付け**：サイドパネル内のテキストエリアに貼り付けてカウント
  - **ファイル**：`.txt` / `.docx` ファイルをドラッグ＆ドロップしてカウント
- **除外ルールの自動適用** — 見出し・URL・引用行・リストマーカー・価格表記などを自動除外
- **テキストプレビュー** — 除外処理後のテキストをサイドパネル内で確認できます
- **要確認項目（警告）** — 見出しタグの不整合などを自動検知

### 校閲チェック（v1.6 以降）

`text_checklist.json` に定義された **226 件のローカルルール** で文章を解析し、検出箇所のハイライト・ジャンプ・改善案提示を行います。

| 検出方式 | 対応 detection_type | 件数 | 主な対象 |
|---------|--------------------|------|---------|
| 文字列一致 | `exact` / `dictionary` | 186 | ひらがな・カタカナ・漢字の表記揺れ、誤用しやすい言葉、話し言葉、フリールール |
| 正規表現 | `regex` | 11 | 半角カタカナ、全角英数字、機種依存文字、日付・3桁以上の数字、二重否定、形容詞+です など |
| 文単位の数値判定 | `sentence_metric` | 3 | 一文100文字以上、読点4つ以上、50文字以上で読点なし |
| 連続・揺れ判定 | `sequence` | 3 | 同じ文末表現の連続、同じ助詞の連続、表記揺れ |
| 簡易ヒューリスティック | `heuristic` | 3 | 体言止め、主述関係が不明瞭、過剰な丁寧語 |
| 自動検出対象外 | `manual` | 20 | わかりやすさ・公の発信のチェックリスト（手動確認） |

### 検出箇所のハイライト・ジャンプ

- **プレビュー内ハイライト**：検出箇所はインラインでハイライト
  - 語句単位（`kind=span`）は黄色背景
  - 文単位（`kind=sentence`）はティールの下線（spanと重ねて視認可能）
- **チップ／ハイライトのクリックでジャンプ**：プレビュー内のスクロール＋強調表示
- **同じキーワードが複数回出ても個別検出**：それぞれが独立したチップとしてクリック可能
- **ページ内ジャンプ（自動タブ）**:
  - 語句単位：単一テキストノード内で確実にジャンプ
  - 文単位：クロスノードのプレフィックス検索でベストエフォート対応

## インストール方法（開発者モード）

1. このリポジトリをクローンまたは ZIP でダウンロードして展開します
2. Chrome で `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. ダウンロードしたフォルダ（`manifest.json` があるディレクトリ）を選択します

## 使い方

1. カウント・校閲したいページを開きます
2. Chrome ツールバーの **TextCount アイコン** をクリック → 画面右側にサイドパネルが開きます
3. サイドパネル上部の **機能タブ**（文字数カウント / 校閲チェック）を選びます
4. 続けて **入力タブ**（自動 / 貼り付け / ファイル）から入力方法を選びます

### 入力タブ：自動

ページ上でテキストを選択するだけで自動的にカウント・校閲チェックされます。

### 入力タブ：貼り付け

テキストエリアに任意のテキストを貼り付けて、カウント・校閲チェックします。  
**Googleドキュメントの本文を扱う場合はこのタブを使ってください。**

> Googleドキュメントは 2021 年以降 Canvas ベースのレンダラーへ移行しており、選択テキストを外部から取得できない仕様です。本文を `Ctrl+A` → `Ctrl+C` でコピーし、貼り付けタブに貼り付けてご利用ください。

### 入力タブ：ファイル

ドロップ領域に `.txt` または `.docx` ファイルをドロップ（またはクリックして選択）します。  
原稿ファイル全文を一括でカウント・校閲チェックできます。

## 文字数カウントの除外ルール

| ルール | 対象 | 自動 | 貼り付け / .txt | .docx |
|---|---|:---:|:---:|:---:|
| スペース・改行・タブ | 全角スペース含む空白文字全般 | ✓ | ✓ | ✓ |
| 見出し（DOM） | `h1`〜`h6` タグで囲まれた要素 | ✓ | − | ✓ |
| 引用ブロック | `blockquote` タグで囲まれた要素 | ✓ | − | ✓ |
| 見出しタグ（文字列） | `<h1>`〜`<h6>` がテキストとして含まれる場合（**全角括弧 `＜＞` にも対応**） | ✓ | ✓ | ✓ |
| 引用元・出典行 | `引用元：`、`参照：`、`出典：` などを含む行 | ✓ | ✓ | ✓ |
| URL | `https://`、`http://`、`www.` で始まる文字列 | ✓ | ✓ | ✓ |
| リストマーカー | `・` `●` `○` `►` `▶` `※` および行頭の番号リスト（`1.` `1）` 等） | ✓ | ✓ | ✓ |
| 価格表記 | `¥/￥ + 数値`（例：`¥1,200`）または `数値 + 円`（例：`1,200円`） | ✓ | ✓ | ✓ |

※ プレーンテキスト（貼り付け・.txt）では DOM 構造が無いため、DOM ベースの見出し・引用ブロックは検出できません。  
※ `.docx` は内部で HTML に変換されるため、すべての除外ルールが適用されます。

## 要確認項目（警告）

以下のケースが検出された場合、プレビュー上部に「⚠ 要確認項目」として表示されます。

- 見出しタグに**全角括弧（`＜` `＞`）**が含まれている
- 見出しタグの**開閉数が一致しない**（例：`<h2>` が3個に対し `</h2>` が2個）

警告が表示された場合も、可能な範囲で除外処理は実行されますが、原文の修正を推奨します。

## 校閲チェックの severity と source_tab

校閲結果カードには以下のバッジが表示されます。

### severity（重要度）

| severity | 表示色 | 用途 |
|----------|--------|------|
| `notice` | グレー | 参考情報レベル |
| `info` | ブルー | 一般的な注意 |
| `warning` | イエロー | 修正推奨 |
| `error` | レッド | 強い修正推奨 |
| `critical` | 濃いレッド | 最優先で確認 |

### source_tab（ルールの出典）

| source_tab | 色 | 主な内容 |
|------------|----|---------|
| ルール校正 | 赤系 | 校正系（誤字脱字寄り、13件） |
| ルール推敲 | 緑系 | 推敲・改善寄り（171件） |
| ルール推敲カテゴリ | 紫系 | 規約・体裁寄り（22件） |
| チェックリスト | グレー | 手動確認（20件） |

## ファイル構成

```
├── manifest.json              # 拡張機能の設定（Manifest V3 / side_panel）
├── background.js              # サービスワーカー
├── content.js                 # ページ注入スクリプト（選択検出・テキスト処理・ページ内ジャンプ）
├── sidepanel.html             # サイドパネルのHTML
├── sidepanel.css              # サイドパネルのスタイル
├── sidepanel.js               # サイドパネルのロジック（カウント・校閲描画・ジャンプ）
├── proofreading.js            # 校閲チェックエンジン（detector ディスパッチャ）
├── mammoth.browser.min.js     # .docx → HTML 変換ライブラリ
├── text_checklist.json        # 校閲ルール（実装の正本・226件）
├── text_checklist.csv         # 校閲ルール（人間用・管理確認）
├── text_checklist.md          # 校閲ルール（人間用・管理確認）
├── rules/proofreading_rules.json   # 旧スキーマ（参考用に残置、拡張からは読まない）
├── requirements.md
└── README.md
```

### 使用ライブラリ

- [mammoth.js](https://github.com/mwilliamson/mammoth.js)（BSD 2-Clause License）— `.docx` ファイルを HTML に変換するために使用

### 校閲ルールの更新方法

- 拡張機能が読むファイル名は固定（`text_checklist.json`）
- 別名ファイル（`*_v2.json` / `*_latest.json` 等）は作らない
- 過去バージョンは Git の commit 履歴で管理
- CSV / JSON / MD は同じファイル名のまま上書き更新する
