# TextCount

ウェブページで選択したテキストの文字数を、指定ルールで自動カウントする Chrome 拡張機能です。  
サイドパネルが常時表示され、テキストを選択するだけでリアルタイムに結果が反映されます。

---

## 機能

- **リアルタイム同期** — テキストを選択すると自動的にカウント結果がサイドパネルに表示されます
- **Googleドキュメント対応** — Googleドキュメント上での文字数カウントに対応しています
- **除外ルールの自動適用** — 見出し・URL・引用行・リストマーカーなどを自動除外し、本文の文字数のみをカウントします
- **テキストプレビュー** — 除外処理後のテキストをサイドパネル内で確認できます

---

## 動作環境

- Chrome 116 以上（Side Panel API を使用）
- Manifest V3

---

## インストール方法（開発者モード）

1. このリポジトリをクローンまたは ZIP でダウンロードして展開します
2. Chrome で `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. ダウンロードしたフォルダ（`manifest.json` があるディレクトリ）を選択します

---

## 使い方

1. カウントしたいテキストが含まれるページを開きます
2. Chrome ツールバーの **TextCount アイコン** をクリックすると、画面右側にサイドパネルが開きます
3. ページ上でテキストを選択すると、サイドパネルに自動的に文字数が表示されます

> **Googleドキュメントで使用する場合**  
> サイドパネルを開いた状態でテキストを選択してください。  
> ページをリロード後に初めて使用する場合も同様です。

---

## 除外ルール一覧

選択範囲に以下が含まれる場合、自動的にカウントから除外されます。

| ルール | 対象 |
|---|---|
| スペース・改行・タブ | 全角スペース含む空白文字全般 |
| 見出し | `h1`〜`h6` タグで囲まれた要素 |
| 引用ブロック | `blockquote` タグで囲まれた要素 |
| 引用元・出典行 | `引用元：`、`参照：`、`出典：` などを含む行 |
| URL | `https://`、`http://`、`www.` で始まる文字列 |
| リストマーカー | `・` `●` `○` `►` `▶` `※` および行頭の番号リスト（`1.` `1）` 等） |

## サイドパネルの見方

```
┌─────────────────────┐
│ TextCount    [同期中] │  ← 選択中は緑のバッジが表示
├─────────────────────┤
│  カウント対象文字数   │
│       1,234 文字     │  ← 除外後の文字数
├─────────────────────┤
│ 元文字数    1,500 文字│
│ 除外文字数    266 文字│
├─────────────────────┤
│ 適用した除外ルール   │
│ ✓ スペース・改行を除外│
│ ✓ URL を除外         │
├─────────────────────┤
│ 除外後テキストプレビュー│
│ （プレビューテキスト）  │
└─────────────────────┘
```

## ファイル構成

```
├── manifest.json      # 拡張機能の設定ファイル
├── background.js      # サービスワーカー（サイドパネルの起動設定）
├── content.js         # ページに注入されるスクリプト（選択検出・テキスト処理）
├── sidepanel.html     # サイドパネルのHTML
├── sidepanel.css      # サイドパネルのスタイル
├── sidepanel.js       # サイドパネルのロジック
├── popup.html         # （旧ポップアップ・未使用）
├── popup.css          # （旧ポップアップ・未使用）
└── popup.js           # （旧ポップアップ・未使用）
```
